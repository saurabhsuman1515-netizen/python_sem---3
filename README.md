# Python – Semester 3

A collection of Python programs, practice exercises, and data-handling notebooks/scripts created during Semester 3. It covers core Python fundamentals and introductory data-science libraries (NumPy, Pandas, Matplotlib).

## Repository Structure

```
python_sem---3/
├── NUMPY/            # NumPy practice: arrays, indexing, operations
├── Pandas/           # Pandas practice: DataFrames, CSV read/write, data cleaning
├── matplotlib/       # Matplotlib practice: plots and visualizations
├── 1st.py            # Basic Python practice
├── 2nd.py            # Basic Python practice
├── calculator.py     # Simple calculator program
├── datatypes.py      # Python data types (int, float, str, list, tuple, set, dict)
├── python_numbers.py # Working with numbers
├── question.py       # Practice questions / exercises
├── slicing.py        # Slicing of strings and lists
├── strings.py        # String methods and operations
├── ultimate.py       # Combined practice program
├── book.csv          # Sample dataset used in Pandas exercises
├── output1.csv ...   # Output files generated by Pandas scripts
│   └── output5.csv
└── tempCodeRunnerFile.py  # Auto-generated by VS Code Code Runner (temporary)
```

## Topics Covered

- **Python basics:** data types, numbers, strings, slicing, input/output
- **Programs:** calculator and practice questions
- **NumPy:** array creation, indexing, and numerical operations
- **Pandas:** loading CSV data, DataFrame operations, exporting results to CSV
- **Matplotlib:** plotting and visualizing data

## Requirements

- Python 3.8 or higher
- Libraries:
  - `numpy`
  - `pandas`
  - `matplotlib`

Install them with:

```bash
pip install numpy pandas matplotlib
```

## Getting Started

1. **Clone the repository**

   ```bash
   git clone https://github.com/saurabhsuman1515-netizen/python_sem---3.git
   cd python_sem---3
   ```

2. **Run any script**

   ```bash
   python calculator.py
   python strings.py
   ```

3. **Run the data-science exercises** from inside their folders, for example:

   ```bash
   cd Pandas
   python <script_name>.py
   ```

   > Some Pandas scripts read `book.csv` and write `output*.csv`, so run them from a location where the relative path to the CSV resolves correctly.

## Notes

- `__pycache__/` and `tempCodeRunnerFile.py` are auto-generated and can be safely ignored (consider adding them to a `.gitignore`).
- `output1.csv` – `output5.csv` are results produced by the Pandas scripts and can be regenerated.
